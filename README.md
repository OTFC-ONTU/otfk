# Сайт Одеського технічного фахового коледжу ОНТУ

[![Тести](https://github.com/gotthejuicee/otfk/actions/workflows/tests.yml/badge.svg)](https://github.com/gotthejuicee/otfk/actions/workflows/tests.yml)

Сучасний сайт коледжу: швидка публічна частина + повноцінна адмінпанель українською. Усе наповнення редагується без жодного рядка коду.

## Можливості

- **Новини** — вподобайки та перегляди без реєстрації, кнопки «поділитися» (Facebook / Telegram / Viber), автопостинг нових новин у Telegram-канал, лайтбокс для фото, фільтр за роками, блок «цього дня в коледжі» з архіву
- **Для вступників** — профорієнтаційний квіз «яка спеціальність підходить», FAQ з розміткою для Google
- **Події** — календар із кнопками «додати в Google Calendar / .ics»
- **Розклад дзвінків** — дві зміни з окремими картками та живим індикатором усіх поточних пар у шапці; друга зміна й індикатор вимикаються в адмінці
- **Контент** — документи, спеціальності, структура й персональні сторінки працівників, фотогалереї, відео, «Коледж у цифрах»
- **Зручності** — пошук із фільтрами типу, пагінацією та живими підказками, банер термінових оголошень, прелоад сторінок, приватна аналітика відвідувань (без кук і сторонніх сервісів)
- **SEO** — sitemap, Open Graph, JSON-LD (NewsArticle, Event, Course, FAQPage), захисні HTTP-заголовки
- **Адмінка** — Filament: дашборд із графіками, швидкі дії, керування контентом і налаштуваннями, попередній перегляд незбережених форм, чернетки й перевірка внутрішніх посилань

Двомовність у розробці: підготовлено маршрути `/en`, перекладено шапку та футер, стандартні підписи меню; власний англійський підпис можна задати в Filament (`label_en`). Перемикач УКР/EN веде до того самого матеріалу з параметрами пошуку та фільтрів. Публічні посилання, форми, квіз, пагінація, RSS і посилання всередині HTML матеріалів зберігають мову. Для сторінок і новин реалізовано англійські поля, окрему публікацію та стан актуальності перекладу в Filament. HTML перекладу вставляється без зміни розмітки; опублікований переклад відображається на `/en`, у картках і RSS. Без нього матеріал показується цілком українською. В адмінці можна змінювати лише оригінал без негайного перекладу нового поля: публікація та попередній хеш зберігаються, неповний переклад тимчасово повертає весь матеріал до української. Увімкнення публікації або зміна англійських полів вимагає повного перекладу. Перекладено статичний інтерфейс публічних сторінок, форми, кнопки, квіз і повідомлення; пошук та підказки на `/en` знаходять опубліковані англійські заголовки, описи й тексти Page/News, а без перекладу — українські заголовки. Додано англійські поля й окрему публікацію спеціальностей, підрозділів і освітніх програм: переклад потрібен для всіх заповнених текстових полів оригіналу, без повного перекладу матеріал цілком український. Переклади використовуються у списках, деталях і результатах квізу; англійський пошук спеціальностей також шукає за опублікованим перекладом. Файли програм спільні для обох мов. FAQ, події та категорії новин також мають англійські поля, окрему публікацію та стан актуальності в адмінці. Перекладено їхній публічний вивід і JSON-LD; події використовують переклад і в ICS, Google Calendar та підказках пошуку. Відповіді FAQ й описи подій — звичайний текст. Додано переклади персоналу та питань/варіантів квізу з публікацією й актуальністю в Filament. Картки персоналу, підписи фото та ініціали використовують повний переклад; питання квізу з усіма варіантами показується однією мовою — англійською лише після публікації всіх його перекладів. Бали та зв’язки зі спеціальностями спільні. Документи та їхні категорії, відео й галереї також підтримують англійські поля, публікацію та актуальність перекладів. Англійський пошук документів працює за перекладеними назвою й описом; файли спільні. Відео перекладають назви й alt у каталозі та на головній, сам ролик залишається спільним. Галерея показується однією мовою: англійською лише після публікації перекладу альбому та всіх непорожніх підписів фото; підписи редагуються у вкладених секціях Filament. Додано переклади банерів (заголовок, підзаголовок, alt, кнопка), плиток і партнерів, підписів статистики. Числа, зображення, URL і видимість спільні. Публічні текстові налаштування також мають переклад: бренд, опис сайту, текст підвалу, адреса, години роботи, оголошення та позначка версії; службові значення залишаються спільними. Мова обирається після читання кешу, який скидається при зміні налаштувань. Міграції застосовує автодеплой; відновлення відсутніх таблиць після старої міграції видалення та повтор часткового MySQL DDL описано в DEPLOY.md. На тестовій БД just-test.shop матеріали перекладено 2026-10-05; потрібні редакторська вичитка, фінальна перевірка та SEO. Це не підтверджує стан інших оточень; `/en` закритий від індексації через `noindex`. Стан і наступні етапи — в [ARCHITECTURE.md](ARCHITECTURE.md).

Вбудовані форми звернень/заявок і блок відгуків вилучено. Публічна CMS-сторінка `/zvorotniy-zvyazok` зі сторонніми посиланнями зворотного зв’язку збережена; її можна редагувати у «Сторінки». Історичні записи старих форм і відгуків у БД не видаляються.

## Стек

Laravel 12 · Filament 3 · Tailwind CSS · Alpine.js · MySQL · PHP 8.3

## Запуск локально

```bash
composer install
npm ci && npm run build   # public/build не комітиться; для продакшену збирається в CI
cp .env.example .env
php artisan key:generate
# вкажіть доступ до порожньої локальної БД у .env, потім:
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

Адмінка — за адресою `/admin` (логін задається у `.env`: `ADMIN_EMAIL` / `ADMIN_PASSWORD`).

Не перезаписуйте наявний `.env`. `migrate --seed` призначено лише для порожнього локального середовища: `SiteSeeder` видаляє частину наявного контенту.

## Тести

```bash
php artisan test
```

Тести виконуються на SQLite у пам’яті й автоматично проганяються в GitHub Actions на кожен push.
