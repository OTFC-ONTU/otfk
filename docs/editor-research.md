# Расширение редактора текста в админке: исследование

Дата: 8 октября 2026 года. Вопрос: как дать редакторам розгортні блоки (как на старой странице «Бібліотека») и почему визуальный редактор «не видит» таблицы, размеры картинок и оформление; какие есть варианты расширения.

> **Обновление 8.10.2026:** выбран вариант C — админка переведена на Filament 4 (ветка `filament-4`), редактор основного текста теперь TipTap с таблицами, розгортними блоками и размерами картинок; исходный HTML без правок не нормализуется (`HtmlStateCast`), режим HTML с кнопками сохранён. Ниже — исследование до обновления.

## Что было до обновления

- Filament **3.3**, поле `RichEditor` = **Trix** (Basecamp). Обёртка `App\Filament\Forms\Components\HtmlRichEditor`: режимы «Візуально / HTML», HTML — CodeMirror 6 с автоформатированием.
- Модель документа Trix жёстко ограничена: абзацы, H1, жирный/курсив/зачёркнутый, ссылки, цитата, код, списки, вложения. **Нет** таблиц, `<details>`, iframe, атрибутов `class`/`style`/`width`/`height`/`align`, выравнивания, цвета, H2–H6 (кроме H1). Всё это Trix при загрузке выбрасывает — поэтому для такого текста в админке стоит защита `isTrixLossy()` и предложение перейти в HTML.
- Расширять сам Trix можно только кнопками-вставками «вложений» (attachment с готовым HTML, который нельзя редактировать внутри) — для таблиц, аккордеонов и размеров картинок это тупик.
- Сайт (`HtmlSanitizer`, `.prose-site`) уже поддерживает таблицы, `details/summary` (единый стиль аккордеона), iframe YouTube/Maps/Docs, `style` по белому списку. Ограничение — именно в редакторе.

## Сделано сразу (8.10.2026)

В режиме HTML над кодом две кнопки (`resources/js/admin/html-sections.js`, тест `tests/Frontend/HtmlSectionsTest.mjs`):

- **«+ Розгортний блок»** — вставляет `<details><summary>…</summary>…</details>`; если выделен HTML, он становится содержимым блока, а заголовок в начале выделения — подписью.
- **«Розділи → розгортні блоки»** — каждый заголовок старшего уровня (H2…H6) вместе с содержимым до следующего такого же заголовка превращается в блок. Отмена — Ctrl/Cmd+Z.

### Как вернуть вид старой «Бібліотеки»

На старом сайте 20 панелей, из них «Культмасові заходи» содержит 15 вложенных. В новом тексте все 20 стали заголовками H4 (импорт расплющил вложенность). Порядок для редактора — отдельно для «Основний текст» и для английского текста:

1. Режим **HTML** → «Розділи → розгортні блоки» (получится 19 блоков; «Культмасові заходи» останется заголовком, так как сразу за ним идёт следующий заголовок).
2. Выделить от `<h4>Культмасові заходи</h4>` до начала блока «Нормативно-правові документи для бібліотек» → «+ Розгортний блок»: 15 блоков окажутся внутри «Культмасові заходи».
3. Зберегти. Проверено локально: 20 блоков, 15 вложенных, стиль единый с «Ліцензування та акредитація».

## Варианты полноценного визуального редактора

| Вариант | Аккордеоны | Таблицы (размеры, объединение) | Картинки (размер, выравнивание) | Сохранение импортированного HTML | Цена перехода |
|---|---|---|---|---|---|
| **A. Оставить Trix + HTML-режим с кнопками** (текущее) | кнопки в HTML | только HTML | только HTML | полное (HTML-режим) | 0 |
| **B. Плагин `awcodes/filament-tiptap-editor` 3.x** (TipTap/ProseMirror для Filament 3) | `details` | `table` | ресайз/кроп при вставке; выравнивание — частично | схема TipTap: неизвестные теги/атрибуты (`style`, `align`, `class`) выбрасываются | низкая: замена поля, без обновления Filament. **Пакет помечен deprecated** — автор рекомендует нативный редактор Filament 4 |
| **C. Обновление до Filament 4** — нативный `RichEditor` на TipTap | `details` | `table` + объединение/разделение ячеек, заголовочные строки | `resizableImages()` (с сохранением пропорций); выравнивание картинок — не заявлено | как B (схема TipTap); есть `customBlocks()` — свои блоки (карточка файла, кнопка, врезка) с предпросмотром | высокая: мажорное обновление всей админки (namespaces Schemas, ресурсы, страницы 2FA/входа, `SettingsFormPage`, тесты Livewire; есть скрипт `filament/upgrade`); своя тема — Tailwind v4 (уже используется на сайте) |
| **D. TinyMCE 7** (плагин `mohamedsabil83/filament-forms-tinymce` для Filament 3) | плагин `accordion` (open source) | свойства таблицы/ячеек: ширина, границы, отступы | размеры, выравнивание, обтекание | лучшая: `valid_elements`/`extended_valid_elements` позволяют сохранить почти любой HTML | средняя: замена поля; лицензия GPL v2+ (`license_key: 'gpl'`, самостоятельный хостинг — подходит), сборка ~500 КБ+, визуально «офисный» интерфейс |
| E. CKEditor 5 (+ General HTML Support) | нет штатного аккордеона (свой плагин) | да, со стилями | да | хорошая через GHS | средняя; GPL или коммерческая лицензия, премиум-функции платные |

Общие ограничения для любых визуальных редакторов:

- Старый импортированный контент (`<p align style="font-size:14pt">`, PDF-iframe с `margin-left`) TipTap-редакторы (B, C) нормализуют при первой правке — для таких текстов HTML-режим остаётся нужен. TinyMCE (D) теряет меньше всего.
- Санитайзер `HtmlSanitizer` остаётся последним барьером: всё, что редактор позволит (новые классы, `style`, атрибуты ширины), нужно добавить в его белые списки, иначе пропадёт при сохранении. Кнопки «цвет текста»/«размер шрифта» стоит сознательно не давать: единый вид сайта держится на `.prose-site`.
- Размеры картинок лучше хранить как `width`/`height` атрибуты или ограниченный набор классов (`img-left`, `img-half`), а не произвольный `style` — это сохраняет адаптивность и CLS.

## Рекомендация

1. **Сейчас:** кнопки HTML-режима (сделано) — закрывают аккордеоны без риска для существующих 1600+ текстов.
2. **Ближайший шаг, если нужен визуальный редактор для таблиц и картинок без мажорного обновления:** пилот **D (TinyMCE)** на одном поле (например, body новостей) с конфигом под наш санитайзер: аккордеон, таблицы, изображения с размерами и выравниванием (классы из короткого списка), без цвета/шрифтов. Оценка: 1–2 дня с тестами и проверкой на типовых импортированных текстах (без потерь при открытии и сохранении).
3. **Стратегически:** **C (Filament 4)** — когда будет окно на обновление админки целиком (после переключения продакшена, не во время SEO-переноса октябрь–декабрь 2026). Тогда же — `customBlocks()` для повторяющихся элементов (карточка файла, контакт, кнопка-ссылка). Вариант B не брать: пакет устаревший и приведёт к той же миграции позже.
